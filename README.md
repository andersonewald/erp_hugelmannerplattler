# 🎭 Hügelmänner Plattler - Sistema ERP / Gestão Cultural

Sistema Web de Gestão ERP desenvolvido para o grupo folclórico de dança alemã **Hügelmänner Plattler** (Domingos Martins - ES). A aplicação centraliza o gerenciamento de integrantes, acervo de danças, controle financeiro, presenças e geração de documentos cadastrais em PDF.

---

## 📌 Funcionalidades Principais

- 👤 **Gestão de Integrantes:** Cadastro completo, dados pessoais, fotos 3x4, dados de saúde/emergência e histórico de vínculo (entrada/saída).
- 🩰 **Acervo de Danças:** Controle de repertório, histórias e significados de cada dança, além da duração e ritmo das músicas.
- 📄 **Ficha do Integrante (PDF):** Geração automática de relatório cadastral formatado para impressão ou download.
- 🔐 **Autenticação & Segurança:** Controle de acesso restrito por login e senha com sessões protegidas.
- 🎨 **Interface Responsiva:** Painel intuitivo e adaptado para dispositivos móveis com visual personalizado do grupo.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Python 3.x
- **Framework Web:** Flask
- **Banco de Dados:** SQLite / MySQL / PostgreSQL (via SQLAlchemy)
- **Front-end:** HTML5, CSS3, JavaScript (ES6+), Bootstrap 5 & Bootstrap Icons
- **Geração de PDF:** WeasyPrint / ReportLab (ou biblioteca correspondente)
- **Template Engine:** Jinja2
